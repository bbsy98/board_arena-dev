# 한수 v0.7.0

장기, 체스, 바둑, 스도쿠를 배우고 AI와 플레이하는 보드게임 학습 앱입니다.

## 계정 및 데이터 저장

- 여러 사용자가 각각 **회원가입**해 계정별 닉네임, 화면 설정, 학습 진행도, 대국 기록을 따로 관리할 수 있습니다.
- 로그인 화면에는 이 기기에 저장된 계정 선택 목록이 표시됩니다. 계정을 선택한 뒤 각자 비밀번호로 로그인하세요.
- 계정과 기록은 앱이 실행되는 기기의 로컬 저장소에 보관됩니다. 인터넷 연결 없이도 게임을 이용할 수 있습니다.
- 같은 Windows 사용자 계정으로 앱을 실행하면 저장된 계정 사이를 전환해 사용할 수 있습니다. Windows 사용자 프로필이 다르면 데이터도 별도로 저장됩니다.
- 기기 교체·앱 데이터 삭제 전에 각 계정으로 로그인해 **💾 백업**을 저장하세요. 백업은 계정별 JSON 파일입니다.
- 로컬 계정은 온라인 서비스 계정이 아닙니다. 앱을 다른 PC나 휴대폰에 설치해도 계정·기록은 자동 동기화되지 않습니다.

## Windows 실행 파일(설치 프로그램) 만들기

이 프로젝트에는 Electron 데스크톱 앱 구성이 포함되어 있습니다. 앱 자체는 인터넷 없이 실행되지만, 설치 프로그램을 처음 만들 때는 Node.js와 패키지를 내려받기 위한 인터넷 연결이 필요합니다.

**방법 A — GitHub에서 자동 빌드(추천)**

1. 이 프로젝트 파일을 저장소 최상위에 커밋합니다. `.github/workflows/build-windows.yml`도 반드시 포함해야 합니다.
2. GitHub 저장소의 **Actions → Build Windows installer**에서 실행이 완료될 때까지 기다립니다.
3. 완료된 실행 기록 하단의 **Artifacts → `hansu-windows-installer`**를 다운로드합니다. ZIP 안에 Windows 설치 프로그램(.exe)이 들어 있습니다.
4. 설치 프로그램을 사용할 PC에 설치합니다. 설치 후 플레이할 때는 인터넷 연결이 필요하지 않습니다.

**방법 B — 내 Windows PC에서 직접 빌드**

1. Windows에 Node.js LTS를 설치합니다: https://nodejs.org/
2. 프로젝트 폴더에서 `scripts/build-windows.bat`을 더블클릭합니다. 또는 터미널에서 `npm install` 후 `npm run dist:win`을 실행합니다.
3. 빌드가 끝나면 `release` 폴더에 Windows 설치 프로그램(.exe)이 생성됩니다.

참고: ZIP에는 빌드 설정과 자동화가 포함되어 있지만, 이 대화 환경에서 Windows용 Electron 설치 프로그램을 실제로 빌드·실행한 것은 아닙니다. 최초 빌드 후 로그인·Worker AI·백업 기능을 확인해야 합니다.

## 휴대폰 앱으로 사용하기

### 가장 간단한 방법: 설치형 웹 앱(PWA)

GitHub Pages에 배포한 HTTPS 주소를 휴대폰 브라우저에서 열고, Android는 브라우저 메뉴의 **앱 설치/홈 화면에 추가**, iPhone은 Safari의 **공유 → 홈 화면에 추가**를 선택합니다. 설치 후 캐시된 화면은 오프라인에서도 사용할 수 있지만, 최초 설치와 업데이트에는 인터넷이 필요합니다.

### 스토어용 Android/iPhone 앱

Google Play 또는 App Store에 올릴 네이티브 패키지는 별도 포장 작업이 필요합니다. 다음 단계에서 Capacitor로 Android APK/AAB 및 iOS 앱을 만들 수 있습니다. Android 빌드에는 Android Studio가, iOS 빌드·서명에는 macOS와 Xcode가 필요합니다.

**중요:** Windows 앱, PWA, 모바일 앱은 각자 별도의 로컬 저장소를 사용합니다. 자동 동기화 서버를 만들지 않는 한, 기기 간 진행도 이동은 계정별 백업/복원으로 처리해야 합니다.

## GitHub Pages 배포

1. 저장소의 기존 파일을 백업합니다.
2. 이 폴더 안의 `index.html`, `css`, `js`, `workers`, `manifest.webmanifest`, `service-worker.js`를 저장소 최상위에 모두 업로드합니다.
3. GitHub 저장소의 **Settings → Pages**에서 `Deploy from a branch`, `main`, `/ (root)`를 선택합니다.
4. 배포 후 강력 새로고침(`Ctrl+F5`)합니다.

## 중요

- 계정과 기록은 서버 계정이 아니라 현재 브라우저에 저장되는 로컬 계정입니다.
- 다른 기기로 옮기려면 앱의 백업/불러오기 기능을 사용하세요.
- 폴더 구조를 유지해야 게임 AI Worker가 정상적으로 실행됩니다.
