# 한수 v0.6

장기, 체스, 바둑, 스도쿠를 배우고 브라우저 AI와 플레이하는 정적 웹앱입니다.

## GitHub Pages 배포

1. 저장소의 기존 파일을 백업합니다.
2. 이 폴더 안의 `index.html`, `css`, `js`, `workers`, `manifest.webmanifest`, `service-worker.js`를 저장소 최상위에 모두 업로드합니다.
3. GitHub 저장소의 **Settings → Pages**에서 `Deploy from a branch`, `main`, `/ (root)`를 선택합니다.
4. 배포 후 강력 새로고침(`Ctrl+F5`)합니다.

## 중요

- 계정과 기록은 서버 계정이 아니라 현재 브라우저에 저장되는 로컬 계정입니다.
- 다른 기기로 옮기려면 앱의 백업/불러오기 기능을 사용하세요.
- 폴더 구조를 유지해야 게임 AI Worker가 정상적으로 실행됩니다.

## v0.6 변경점

- 단일 HTML을 CSS, 공통 코드, 게임별 코드, 엔진, Worker로 분리
